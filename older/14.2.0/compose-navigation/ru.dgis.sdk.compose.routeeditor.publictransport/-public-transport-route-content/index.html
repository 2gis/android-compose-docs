PublicTransportRouteContent

interface PublicTransportRouteContent

Interface defining all customizable composable parts of the public transport route card.

Allows users to customize individual parts by providing custom implementations for specific ones (e.g., custom colors, icons, or completely replacing the part).

Use DefaultPublicTransportRouteContent for default implementations, or create a custom implementation using Kotlin delegation to override only specific components:

object MyPublicTransportRouteContent : PublicTransportRouteContent by DefaultPublicTransportRouteContent {
    @Composable
    override fun GoButton(
        viewModel: PublicTransportRouteViewModel,
        icons: PublicTransportRouteComposableIcons,
        colors: RouteCardColors,
    ) {
        // Custom "Go" button implementation
    }
}
