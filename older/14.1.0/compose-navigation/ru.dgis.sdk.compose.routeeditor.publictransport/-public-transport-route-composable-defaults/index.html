PublicTransportRouteComposableDefaults

object PublicTransportRouteComposableDefaults

Default configuration values for the public transport route composable.

This singleton object provides pre-configured instance of PublicTransportRouteComposableIcons using the SDK's standard resource references. These defaults can be used directly in composables or overridden with custom values to customize the appearance of the route display.
