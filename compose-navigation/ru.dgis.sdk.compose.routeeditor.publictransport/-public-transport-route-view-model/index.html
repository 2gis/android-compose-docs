PublicTransportRouteViewModel

interface PublicTransportRouteViewModel

Provides all necessary data and actions for rendering and controlling the public transport route card in the RouteEditor.

This ViewModel encapsulates the business logic and state for displaying a detailed multi-modal itinerary, including walking segments, public transport legs, intermediate stops, and interactive controls (e.g., expanding stops, starting navigation).
